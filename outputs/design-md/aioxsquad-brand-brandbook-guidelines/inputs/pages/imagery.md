## ◤ ART DIRECTION — RULES — NO PHOTOS · NO GRADIENTS · NO ILLUSTRATIONS

### / MEDIA

- ✓ ASCII art, character grids, CLI screens
- ✓ SVG wireframes · 1px stroke · no fill
- ✓ Oversized type as image — the word IS the picture
- ✕ Stock photography of any kind
- ✕ Gradients, blurs, glassmorphism
- ✕ 3D renders, AI-generated imagery

### / COLOR

- ✓ Two-tone only: cream on near-black
- ✓ Lime accent sparingly — single element per frame
- ✕ Duotone photo treatments
- ✕ Color washes, overlays, blends
- ✕ Warm or pastel palettes

### / COMPOSITION

- ✓ Grid-aligned · monospace metrics
- ✓ Hard crops · flush edges · no soft fades
- ✓ Generous negative space — let the canvas breathe
- ✕ Centered single-subject "hero shots"
- ✕ Drop shadows, rounded corners
