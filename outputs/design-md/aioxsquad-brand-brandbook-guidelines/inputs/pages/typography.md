## 01 — Typography (Font Families & Scale)

### Display / Headlines

**TASA Orbiter Black**

```
ABCDEFGHIJKLMNOPQRSTUVWXYZ
0123456789 !@#$%&*
```

- `--font-bb-display` // TASA Orbiter Display 800
- Role: H1–H4, Titles, Impact

### Sans / Primary

**Geist Semibold**

```
ABCDEFGHIJKLMNOPQRSTUVWXYZ
abcdefghijklmnopqrstuvwxyz
0123456789 !@#$%&*
```

- `--font-bb-sans` // Geist 400–700
- Role: Body, UI, Labels

### Mono / Technical

**Roboto Mono Medium**

```
ABCDEFGHIJKLMNOPQRSTUVWXYZ
abcdefghijklmnopqrstuvwxyz
0123456789 {}<>[]()=>
```

- `--font-bb-mono` // Roboto Mono 400–500
- Role: Code, Labels, Nav, HUD

## Type Scale

| Size | Role | Notes |
|---|---|---|
| 4rem | Display | AIOX hero |
| 2.5rem | H1 | Page Title |
| 1.5rem | H2 | Section Title |
| 1rem | Body | "The quick brown fox jumps over the lazy dog." |
| 0.8rem | Small | Secondary text, descriptions, and supporting content. |
| 0.65rem | Label | HUD Labels // Navigation // Status |
| 0.6rem | Micro | Footer Meta // Class Names // Refs |
