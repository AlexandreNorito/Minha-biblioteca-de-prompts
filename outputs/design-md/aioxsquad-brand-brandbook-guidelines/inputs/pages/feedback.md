# Feedback — AIOX Brandbook

Source: https://brand.aioxsquad.ai/brandbook/feedback

## 01 — Alerts

| Variant | Title | Body |
|---|---|---|
| Info | Information | Informational alert message. |
| Success | Success | Operation completed successfully. |
| Warning | Warning | Please review before proceeding. |
| Error | Error | Something went wrong. |

## 02 — Toasts

| Variant | Body |
|---|---|
| Success | "Changes saved" ✕ |
| Error | "Connection failed" ✕ |
| Warning | "Storage 92% full" ✕ |
| Info | "Update available" ✕ |

## 03 — Modal

- Open Modal → Dialog Modal

## 04 — Notification Center

- Bell icon with unread badge (e.g. `2`)
- Tray opens "Notifications (2 unread)" panel

## 05 — Empty States

| Variant | Title | Body | CTA |
|---|---|---|---|
| Default | Nenhum item | Não há itens para exibir. | Criar item |
| Search | Sem resultados | Tente termos diferentes. | Limpar busca |
| Error | Algo deu errado | Erro inesperado. | Tentar novamente |
| Permissions | Acesso restrito | Solicite acesso ao admin. | — |

## 06 — Loading Overlay

- Container Overlay (toggle 3s "Ativar" button)
- Spinner Sizes: SM · MD · LG

## 07 — Confirm Sheet

- Variants: Default · Destructive · Loading
- CTA verb: "Abrir {variant}"
