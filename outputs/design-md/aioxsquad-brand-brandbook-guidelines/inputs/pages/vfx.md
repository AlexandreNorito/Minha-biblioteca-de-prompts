# VFX System — AIOX Brandbook

## 01 — Film Grain (Texture Overlay)

| Step | opacity |
|---|---|
| Subtle | 0.05 |
| Light | 0.10 |
| Medium | 0.15 |
| Heavy | 0.25 |

## 02 — Blend Modes (CSS Mix-Blend)

`multiply` · `screen` · `overlay` · `soft-light` · `color-dodge` · `difference`

## 03 — Blur Effects (Backdrop Filter)

| Level | Value |
|---|---|
| No Blur | `backdrop-filter: blur(0px)` |
| Subtle | `backdrop-filter: blur(4px)` |
| Medium | `backdrop-filter: blur(8px)` |
| Heavy | `backdrop-filter: blur(16px)` |

## 04 — Glow Effects (Box Shadow & Text Shadow)

- **Neon Glow** — `box-shadow: 0 0 8px rgba(var(--bb-accent-rgb), 0.4), ...`
- **Soft Glow** — `box-shadow: 0 0 16px rgba(var(--bb-accent-rgb), 0.15...)`
- **Ring Glow** — `box-shadow: 0 0 0 2px rgba(var(--bb-accent-rgb), 0.3...)`
