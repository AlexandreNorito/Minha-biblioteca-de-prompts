## Design Principles

- **◼ Dark-First** — Background `#050505` como base. Superfícies `#0F0F11`. Informação emerge da escuridão.
- **◆ Neon Lime Accent** — `#D1FF00` como cor de destaque única. CTAs, status ativo, dados positivos.
- **⌘ Monospace Voice** — RobotoMono para labels. TASAOrbiter para títulos. Geist para corpo.
- **⊞ Grid Precision** — Layouts baseados em grid com gap de 1px e border como separador.
- **⚠ HUD Language** — Section dividers como cockpit readouts. Corner brackets. Hazard stripes.
- **◎ Data-Dense** — Otimizado para exibir informação densa — KPIs, rankings, métricas.
