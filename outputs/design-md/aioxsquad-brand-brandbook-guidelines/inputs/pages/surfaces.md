## 01 — Surfaces & Borders (Elevation · Borders · Radius · Glass)

| Token | Value | Role |
|---|---|---|
| `--bb-dark` | `#050505` | Page base. Canvas background. |
| `--bb-surface` | `#0F0F11` | Elevated cards, panels, headers. |
| `--bb-surface-alt` | `#1C1E19` | Secondary elevation. Nested panels. |
| `--bb-surface-deep` | `oklch(0.13 0 0)` | Deep recessed areas. Code blocks. |
| `--bb-surface-overlay` | `rgba(15,15,17,0.92)` | Transparent overlay on modals. |
| `--bb-surface-panel` | `oklch(0.15 0.005 280)` | Sidebar panels, nav drawers. |
| `--bb-surface-console` | `oklch(0.11 0.005 280)` | Terminal/console backgrounds. |
| `--bb-surface-hover-strong` | `oklch(0.22 0.06 283)` | Strong hover state. Interactive surfaces. |
